# DeepSkill

**一份经过实战检验的 AGENTS.md 技能文件，专为 DeepSeek V4 Pro 打造 —— 让 AI 编程助手从"又快又糙"变成"一次做对"。**

---

## 这是什么？

一个 `AGENTS.md` 文件，通过向系统提示词注入五项核心工程纪律，显著提升 AI 编程助手（尤其是 **DeepSeek V4 Pro**）的代码质量和可靠性：

| # | 技能 | 核心理念 |
|---|------|----------|
| 1 | **预判与风险分析** | 先想清楚再动手，改代码前先评估影响面 |
| 2 | **自检与验证** | 每次改动后用工具验证，而非凭记忆 |
| 3 | **精确操作** | 批量修改时精度优先于速度 |
| 4 | **环境感知** | 写代码前先确认编译环境 |
| 5 | **完整性保障** | 同类问题一次扫清，不分散到多轮修改 |

## 核心原则

> **想清楚 → 做一遍 → 验证完 → 结束**
>
> 而不是：先做 → 编译报错 → 再修 → 再报错 → 再修 → 终于通过

**慢就是快。** 一次做对的时间成本远低于返工的时间成本。

## 快速上手

### 全局生效（所有项目）

将 `AGENTS.md` 复制到用户主目录：

```bash
# Linux / macOS
cp AGENTS.md ~/AGENTS.md

# Windows
copy AGENTS.md %USERPROFILE%\AGENTS.md
```

### 单项目生效

将 `AGENTS.md` 复制到项目根目录：

```bash
cp AGENTS.md /path/to/your/project/AGENTS.md
```

AI 助手会自动加载该文件作为系统指令。

## 为什么有效？

大多数 AI 编程助手**手快脑慢** —— 不分析影响就直接改代码、改完不验证、全局替换不检查副作用。这导致一个令人抓狂的循环：编译报错、引用缺失、构建失败。

这份技能文件安装了**五道思维护栏**，强制助手做到：

- **先分析再动手** —— 杜绝"先改再说"
- **每次改动后验证** —— grep 确认，而非凭感觉
- **精度优先于速度** —— 一次正确的修改胜过五次错误的尝试
- **感知环境变化** —— `.c` 和 `.cpp` 有区别，编译选项很重要
- **彻底完成** —— "大部分改了"不等于"完成了"

## 已测试平台

- **DeepSeek V4 Pro**（主要目标，效果优秀）
- 兼容所有支持 `AGENTS.md` 系统提示词的 AI 编程工具（如 opencode、Cursor 等）
